# YouTube Morphe

[![CI](https://img.shields.io/github/actions/workflow/status/logvinenko44912-del/YouTube-Morphe/build.yml?style=flat-square&label=CI)](https://github.com/logvinenko44912-del/YouTube-Morphe/actions)

Get the [latest CI release](https://github.com/logvinenko44912-del/YouTube-Morphe/releases/latest).

## Features

- Updated with the latest versions of Morphe patches.
- Cleans APKs from unneeded libs to make them smaller.
- Fully open-source, every binary or APK is compiled without human intervention.
- APKs (no root required):
  - Ready-to-install signed YouTube APK.
  - Can be updated directly from within Obtainium or by installing a new APK.
  - Works on both rooted and non-rooted devices.

## Notes

- Use [zygisk-detach](https://github.com/j-hc/zygisk-detach) to block Play Store from updating YouTube (root users).
- Non-root versions of YouTube require **Morphe MicroG-RE** to work.
- If installation fails due to a signature mismatch, uninstall the stock/previous version of YouTube first.
